# 四个候选模型与基线的组合回测（2022–2025，冻结 TEST 预测）

**目的**：为「哪些模型可用」提供 RankIC 门控之外的组合层证据。所有分数都读自已签名的冻结预测工件，**没有重新推理、没有重新训练、没有访问数据库**；标签读自同一组冻结 TEST 面板。脚本 `run_backtest.py` 只读，结果 `backtest_results.json`（含每个标签分片的 sha256）。

## 1. 口径（先说清，否则数字会被误读）

- **标签语义**（来自 `research_v2/src/research_v2/labels/forward_return.py`）：`raw_return_5d = 复权开盘价(T+6) / 复权开盘价(T+1) − 1`，即信号日 T 的**次日开盘买入、持有 5 个交易日、第 6 日开盘卖出**。复权价，已处理分红送股。仅使用 `label_valid=True` 且收益有限的行。
- **重叠处理**：信号是逐日的、持仓是 5 日，直接平均会重复计数并掩盖自相关。做法是把连续 5 个信号日归为一个 **cycle**——一个 cycle 恰好是「每日投入 1/5 资金的错层组合」的一次不重叠往返，因此 cycle 序列就是该策略的真实收益序列，按 `243/5 = 48.6` 个 cycle/年年化。共 **192 个 cycle**（960 个信号日，另 9 日凑不满一个 cycle 被丢弃）。
- **权重**：等权。工件里没有市值或价格水平，市值加权**不可计算**，因此没有做。
- **四个模型共用同一组冻结标签**：四个工作区的 dataset id 与行数逐折完全相同（F1 `226a8dfc497c`/3,798,054 行，F2 `eb9bba1b5a0b`/4,205,787，F3 `9766e69f3425`/4,582,910，F4 `6f9478d7645c`/4,893,642），基线预测在各工作区也是**逐字节相同的同一份**（每折 scores sha256 一致：F1 `bf62ef60`、F2 `aa5b21a7`、F3 `566d2ef9`、F4 `30e7a978`；折级选择 F1–F3=B2、F4=B3）。所以跨模型与对基线的比较是同口径的。
- **成本是假设，不是测量**：工件里没有任何成本数据。下文 `NET` 用「实测换手 × 假设的单边往返成本」扣减，默认 30bp，并给出 0/15/30/50/80bp 的敏感性。`GROSS` 是不扣成本的实测值。

## 3. 三个必须一起引用的结论

**（1）模型的价值集中在尾部，不在宽五分位。** 在 q5（约 700 只）上**基线不输给任何模型**：毛年化 18.86% 对 M0R 18.51%、M1 17.64%、M2 17.04%。而在 top50 上基线只有 16.07% 毛年化，模型是 21.4%–22.6%。**换句话说，这些模型擅长挑出最好的几十只，不擅长给整个前 20% 排序。**

**（2）M2 在集中持仓上是最好的，且对成本假设稳健——尽管它没有通过 G4/G6 门控。** 净年化在 0/15/30/50/80bp 五个成本档上 M2 都排第一（top50：22.55 / 18.99 / 15.43 / 10.68 / 3.56%）；80bp 时基线已经 −2.60%、M1 只剩 +0.29%，M2 还有 +3.56%。原因是 M2 换手最低（0.488 对 M1 的 0.551）。

  这与门控结论**方向相反，但不矛盾**：G4 用的是**全截面 RankIC**，它对分布中段与两端等权；而 top50 只关心极端尾部。M2 是「中段排得差、尾部挑得准」，所以 RankIC 增量差 4.08e-05 没过线，组合层却最强。**如果筛选标准是「实盘选股打分」，M2 的门控失败不应该被直接读成「M2 不可用」。**

**（3）逐年稳健性：只有 M2 在四年里每一年都跑赢基线。** 候选减基线的净年化差（百分点）：

**一个实现细节必须写明**：`top-N` 的选股规则是「分数 ≥ 第 N 名的分数」，因此遇到并列会多持几只。M0-refined 的分数并列较多，实际平均持有 **52.7 只**（top50）与 **105.0 只**（top100），其余模型都是 50.0–50.2 与 100.0–100.1。这让 M0-refined 的两个集中组合与别人不是严格同样的持股数——它本来就全面落后，故不影响结论方向，但引用其绝对数值时要带上这一点。

**含义**：换模型不只是换收益数字，而是**换掉大约六到七成实际买入的股票**。所以「哪个模型可用」不能只看年化收益，还要看你愿意持有什么样的股票；反过来说，这么低的相关性也意味着集成有空间。

## 3.2 等权分数集成：略优于任何单模型，且同样只在尾部有效

做法：把 M0R / M1 / M2 的百分位分数**等权平均**，行集取三者都能打分的**交集**（F1 797,239 / F2 876,154 / F3 927,808 / F4 934,656 行，交集宽度由覆盖最窄的 M2 决定），再用完全相同的 cycle 口径与 30bp 成本回测。**为公平起见，基线也被限制到同一批交集行上重算。**

| 组合 | 集成净年化 | 同口径基线净年化 | 差（百分点） | 集成 Sharpe | 基线 Sharpe |
| --- | ---: | ---: | ---: | ---: | ---: |
| top50 | **15.45%** | 8.97% | **+6.49** | **0.747** | 0.366 |
| top100 | **15.71%** | 10.05% | **+5.66** | **0.751** | 0.423 |
| q5 | 14.53% | **14.90%** | -0.36 | 0.685 | 0.666 |

集成明细：top50 毛年化 22.63%、四年累计净 69.42%、最大回撤 −27.46%、换手 0.492；top100 毛年化 21.89%、四年累计净 **70.86%**（全表最高）、最大回撤 −27.37%、换手 0.424（低于任何单模型的 top100）；q5 净年化 14.53%、换手 0.228。

**结论**：集成在 top100 上是整个分析里最好的结果，换手也最低；在 top50 上与 M2 单模型基本打平（Sharpe 0.747 对 0.730）。而在 q5 上集成仍然**略输**基线，第三次印证「价值只在尾部」。

**两条必须说明的限制**：（a）集成只在三个模型都有分数的行上成立，因此继承了 M2 的覆盖缺口，比单模型可选股票池更窄；（b）等权平均百分位分数是最简单的集成方式，没有做过权重优化——**任何在此之上的调权都属于新的搜索，会带来新的选择偏差，本节没有做。**

## 3.3 指定日期出股票打分

`score_date.py` 可从签名工件直接取任一 2022–2025 交易日的打分并给出各模型排名与实际 5 日收益，无需重新推理：

```
python3 score_date.py --date 2025-06-13 --top 50 [--models M0R,M1,M2,M0-refined] [--out scores.csv]
```

例：2025-06-13（F4）各模型可打分股票数为 M0R 3,845、M1 3,840、M2 3,835、M0-refined 3,845；该日 M0R 的 top15 实际 5 日等权收益 −1.953%（胜率 0%），是单个坏日的正常波动，不构成对模型的评价。

**能出分数的日期上限是 2025-12-31**：数据库实测 `factor_daily` 覆盖 2014-01-02 至 **2025-12-31**（106,598,549 行），而 `universe_daily` 与 `label_daily` 到 2026-07-31。**因子止于 2025-12-31，所以 2026 年的任何日期都出不了分数**，必须先补做 2026 因子物化。2022–2025 之间的日期不需要任何计算——四个 TEST 折已覆盖这 969 个交易日的签名分数。

**四条结论：**

1. **以上证综指衡量，所有策略都跑赢。** 上证综指这四年几乎是「失落的五年」——累计只有 +9.26%（几何年化 +2.24%），2022 与 2023 连续下跌，靠 2024–2025 才收复。最弱的 M0-refined（6.13%）也高于指数的 4.62%。
2. **但风格差异极大，这是必须同时说明的一条。** 策略的股票池经过流动性筛选且**等权**，持有大量中小盘；而上证综指是市值加权、由大型国企主导。把最接近该风格的**中证2000**（小微盘）放进来，它做到 **9.90%**——**高于基线 top50 的 9.07%，也远高于 M0-refined 的 6.13%**。也就是说：**基线与 M0-refined 相对上证综指的那点优势，可以完全由「小盘风格」解释，它们相对风格匹配基准并没有超额。** 真正有超额的是 M0R / M1 / M2 与集成（相对中证2000 高出 +3.8 至 +5.8 个百分点）。
3. **2025 年出现了相反的情况：小微盘风格（+42.33%）跑赢了所有策略**（+29.6% 至 +34.4%）。离实盘最近的一年里，单靠风格暴露就能赢过模型，这与第 5 节「2025 是模型超额最弱的一年」是同一个现象的两个侧面。
4. **风险调整后模型明显更好。** 单位回撤换来的年化收益：模型 0.50–0.57，上证综指 0.20，中证2000 0.29，基线 0.25。模型的回撤（−27% 至 −28%）比上证综指（−22.97%）深，但比中证2000（−33.99%）和基线（−36.31%）浅得多——**承担了介于两者之间的风险，换到了接近两倍的收益/回撤比**。

**这条对比不改变第 4 节的限制**：指数比较同样建立在「T+1 开盘可成交」的假设上，没有涨跌停过滤；而指数的绝对水平也依赖 2024–2025 的行情，换一个区间结论会变。

## 4. 这个回测不能证明什么（引用前必读）

1. **没有涨停/跌停可成交性过滤——这是对 top50 结果最大的威胁。** A 股里打分最高的股票常常在 T+1 开盘就涨停、实际买不到，而这种情况**恰恰集中在尾部**，所以 top50 的高收益被高估的程度**大于** q5。工件里没有价格或涨跌停字段，**无法从现有工件修正**；要修正必须引入 T+1 开盘价与涨跌停状态重新过滤。
2. **成本是假设**。已给 0–80bp 敏感性；排序对成本档稳健，但绝对水平不稳健（top50 在 80bp 下基线转负）。
3. **`label_valid` 过滤会剔除进/出场价缺失的行**（停牌等），这带来轻微乐观偏差；四个模型与基线受同样过滤，故比较仍同口径。
4. **等权、无容量与冲击约束**。50 只等权对小资金可行，对大资金不成立；冲击成本未建模（80bp 档可视为粗略代理）。
5. **模型的可选股票池比基线宽**：每个五分位模型约 733 只、基线约 704 只。基线只用 9 个稠密因子，模型多用 6 个稀疏因子——**更宽的选择集本身是候选的设计意图**，但它意味着 top50 的优势里有一部分来自「能从更多股票里挑」，不全是排序能力。
6. **M2 的组合建立在略小的股票池上**：它有 17,306 条有标签但未打分的行（15 条历史门槛所致），每个五分位约 729–730 只对 733 只。
7. **样本量**：192 个 cycle，单年约 48 个，逐年 Sharpe 的置信区间宽，逐年结论应看方向而非小数点。
8. **未做**：多空组合、行业中性化、市值中性化、持仓期非 5 日的变体、以及 2026 年（因子数据止于 2025-12-31，且 2026 标签是锁定段）。
